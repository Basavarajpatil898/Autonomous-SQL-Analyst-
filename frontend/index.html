GETTING STARTED

Connect your database

This workspace needs three services to answer questions:

  1. MySQL or SQLite configured in the Database menu. MySQL can use the sample schema from database/init.sql; SQLite files must be accessible to the backend.
  2. Backend API running at the URL in Settings.
  3. Ollama running locally with the configured model downloaded.

Update the database connection string in backend/.env. You can also configure a Gemini API key there as a fallback.
